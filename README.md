# World Fabric

**World Fabric** is a stand-alone research observatory of the material systems that make globalization possible and of the projects that transform them.

The project is published through GitHub Pages. It is part of the research work indexed on **Ligne de Crête**.

## Core research question

> How are infrastructures, corridors, projects and constraints changing the effective capacity of the systems that carry global flows?

## V1 proof obligations

World Fabric V1 must prove three things:

1. it can represent a strategic corridor coherently;
2. it can show how projects change corridor capacity without confusing announced capacity with usable system capacity;
3. it can produce a documented and credible system-transformation assessment.

The first pilot is the **Middle Corridor / Trans-Caspian International Transport Route**. It is followed by a **Suez–Red Sea** maritime stress test and a **Europe–Asia submarine cable** network stress test.

## Canonical language

English is canonical for the research model, data contracts, taxonomies, methods and published records. French may be used on Ligne de Crête for synthesis and contextual presentation, but is not a second canonical source.

## Foundational rule

> **Every important statement is traceable.**

A material conclusion should be inspectable from published statement to assessment, observation, evidence and source.
