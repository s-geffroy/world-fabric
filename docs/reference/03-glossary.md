# Glossary

**Asset** — concrete physical or digital object that enables a system function.  
**Bottleneck** — functional constraint materially limiting relevant system performance.  
**Canonical Record** — single logical, versioned research object for one World Fabric object.  
**Corridor** — organised end-to-end system of segments, links, assets and services supporting flows.  
**Counter-effect** — adjacent constraint capable of limiting, delaying, displacing or neutralising a project benefit.  
**Dependency** — material reliance on an asset, actor, interface, jurisdiction, technology or service.  
**Effective capacity** — capacity usable in system context rather than isolated nominal capacity.  
**Functional link** — system function such as rail haul, border crossing, port handling or modal transfer.  
**Geographic segment** — spatial subdivision used for navigation and location.  
**Project impact chain** — Project → Asset change → Functional-link change → Corridor metric change.  
**System transformation** — persistent, materially significant change in structure, distribution or effective capacity of a system.  
**Traceability** — ability to move from material statement to analytical basis, evidence and source.  
**Watch item** — development capable of changing the current record assessment.
