# Architecture Decisions — V1 Baseline

## ADR-001 — Stand-alone research identity
World Fabric is a stand-alone research project, published through GitHub Pages and indexed from Ligne de Crête.

## ADR-002 — Canonical language
English is the canonical research language. French synthesis is allowed outside the canonical model.

## ADR-003 — Canonical Record first
The unit of quality is the audited Canonical Record. Database and UI structures support the record rather than determining its narrative.

## ADR-004 — Docusaurus publication shell
Docusaurus is used as the durable static publication shell, with custom React pages for exploration and docs for research inspection.

## ADR-005 — Static GitHub Pages delivery
Public data are exposed as versioned static JSON/GeoJSON/CSV. No server-side API is assumed.

## ADR-006 — No primary single score
Corridor conclusions use multidimensional evidence. Composite capacity is experimental and secondary.

## ADR-007 — Three epistemic states
Observed, expected and scenario are distinct and cannot silently convert into one another.

## ADR-008 — Project impact includes counter-effects
Every material project assessment considers adjacent constraints capable of limiting system impact.

## ADR-009 — Hybrid corridor representation
Geographic segments answer where; functional links answer which function; assets provide concrete evidence.

## ADR-010 — Transformation validation is human
Machines may surface candidate patterns; a canonical transformation requires human analytical validation.

## ADR-011 — Coverage has no object quota
World expansion is governed by inclusion criteria and a region × family × strategic-level coverage matrix.
