# Inspect the Research

World Fabric publishes the methods used to build, validate, industrialize and expand its Canonical Records.

Start with the **Research Charter**, then read the six dossiers in order:

1. Perfect Canonical Record
2. Validation Protocol
3. Production Pipeline
4. Industrialization
5. Global Expansion
6. Intervention Doctrine

The Middle Corridor pilot is the first practical test of the method.
